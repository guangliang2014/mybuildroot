如下命令自动添加和展开到当前工程下面其他git的仓库：
git submodule add <仓库地址> <目标目录>


git submodule add
作用：在主仓库中添加一个新的子模块。如果你想在项目中引入另一个仓库作为子模块，就会使用这个命令。它会：

在当前仓库中创建一个指向子模块仓库的配置条目
下载子模块内容到对应目录




git submodule init
初始化子模块配置，仅创建本地配置文件（.git/config中的子模块配置），但还没有下载内容。常用于克隆仓库后，准备拉取子模块的内容。
git submodule update
下载子模块内容，检出特定版本（即对应父仓库中记录的子模块提交）。这是同步子模块内容的核心命令。

如果修改.gitmodules
git submodule sync
同步子模块配置，确保本地配置和 .gitmodules 文件内容
